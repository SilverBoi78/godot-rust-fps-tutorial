# A first-person shooter in Rust and Godot 4

A round-based survival shooter built with [Godot 4.7.2](https://godotengine.org/)
and [gdext](https://github.com/godot-rust/gdext) — and, at the same time, a
19-lesson tutorial for building it.

There is no game logic in GDScript anywhere in this repository. Scenes are
composed in the Godot editor; every node type in them is a Rust struct.

## What's in here

| Path | What it is |
|---|---|
| [`tutorial/`](tutorial/README.md) | 19 lessons taking you from an empty folder to a working prototype, plus four appendices. |
| `reference/` | A complete, verified build. Every code snippet in the tutorial is copied out of here *after being compiled and run*. |
| [`DESIGN.md`](DESIGN.md) | What the game is, how it is architected, and why. |

## Who this is for

You have read [The Rust Programming Language](https://doc.rust-lang.org/book/)
and understood it. You have not necessarily written much Rust of your own, and
you have never opened a game engine.

That combination is the target. Ownership, traits, enums and `Result` are
assumed; `Gd<T>`, scene trees, physics ticks, collision masks and the
borrow-checker problems peculiar to gameplay code are all taught from scratch.

## Requirements

| Tool | Version |
|---|---|
| Godot | 4.7.2 (standard build — **not** .NET) |
| Rust | 1.94 or newer |
| `godot` crate (gdext) | 0.5.5 |

[Lesson 0](tutorial/00-setup.md) installs all of it on Linux, macOS and Windows.

## Running the reference build

```bash
# 1. Build the extension
cargo build --manifest-path reference/rust/Cargo.toml

# 2. Import once, so Godot discovers the extension and registers the classes.
#    Required after a fresh clone. Skipping it gives you a wall of
#    "Cannot get class 'Main'" errors.
godot4 --headless --path reference/godot --import

# 3. Play it
godot4 --path reference/godot

# The test suite -- 52 checks, no window needed
godot4 --headless --path reference/godot res://tests/tests.tscn
```

## Why Rust for a Godot game

Honestly: for a project this size, GDScript would be faster to write. Rust earns
its place when the codebase gets big enough that "I renamed a signal and three
call sites still compile" becomes a real cost, or when a system is hot enough
that a scripting language's per-call overhead shows up in a profile.

The tutorial says so out loud, repeatedly, and names the places where the Rust
version is genuinely worse than the GDScript one. A tutorial that only ever
tells you its language is great is not teaching you how to choose.

## Assets

There are none. Every mesh is a box, a capsule, or a sphere generated by Godot,
every material is a flat colour, and all audio is synthesised in Rust at
startup. This keeps the repository free of anyone else's work, and it keeps the
lessons about mechanics rather than about art pipelines.
